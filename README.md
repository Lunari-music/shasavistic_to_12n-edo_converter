# shasavistic_to_12n-edo_converter
シャサフ式音楽理論の次元音程を任意の平均律に変換する計算ツール。12*n EDOの「音名+ステップ数」表示に対応し、従来の12平均律向けDAWや五線譜におけるピッチ調整や微小音程の入力をスムーズにします。/A pitch calculator based on Shasavistic music theory. Converts multi-dimensional intervals to any EDO. Supports 12*n EDO "Note + Step" notation to simplify pitch adjustments in standard 12-EDO DAWs and staff notation.
